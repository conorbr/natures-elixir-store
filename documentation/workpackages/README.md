# Work Packages

This folder holds documentation for upcoming and in-progress work packages for Nature's Elixir.

## Purpose

- **Scope**: Define discrete deliverables, timelines, and acceptance criteria
- **Planning**: Break larger initiatives into manageable work packages
- **Tracking**: Reference for sprint planning and client handoff

## Naming

Use descriptive filenames, e.g.:

- `wp-001-storefront-theme.md`
- `wp-002-checkout-improvements.md`

## Suggested structure per work package

1. **Title & summary** – What is being delivered
2. **Scope** – In scope / out of scope
3. **Acceptance criteria** – How we know it’s done
4. **Dependencies** – Other work or systems this relies on
5. **Rough estimate** – Optional time/effort
6. **Notes** – Links, decisions, client preferences
